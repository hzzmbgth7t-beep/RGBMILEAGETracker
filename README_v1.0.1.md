# RGB Mileage Tracker

Version 1.0.1

RGB Mileage Tracker is a browser-based Progressive Web App for private vehicle mileage, maintenance, insurance, and ownership tracking.

## What's New in v1.0.1

- Added manual location capture on fuel entries.
- Added Location field to fuel entries and history.
- Added "Use Current Location" workflow.
- Added station detection prompt flow:
  - Use This Station?
  - Location Only
  - Cancel
  - Add To Station Drop Down List?
- Added Clear Location.
- Stores display address plus latitude and longitude for future use.
- Added station and location reporting support.
- Fixed iPhone Home Screen icon support by placing icons at the root and adding Apple touch icon tags.

## Installation through GitHub Pages

1. Unzip this package.
2. Upload all files directly to the root of your GitHub repository.
3. Enable GitHub Pages using the main branch and root folder.
4. Open the GitHub Pages address in Safari.
5. Use Share > Add to Home Screen.

## Important Notes

- Location is only captured when the user taps Use Current Location.
- Address/station lookup requires internet access.
- Data is stored locally in the browser on the device.
- Export or backup regularly.
