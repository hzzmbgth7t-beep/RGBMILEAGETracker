# RGB Mileage Changelog

Version 1.1.0  
Release Date: 2026-06-03

## Build Type

Clean build.

## Added

- Editable vehicle-circle long press behavior.
- iPhone image context-menu suppression for Home Screen vehicle circles.
- Manage Vehicle Order and Swap Vehicle Positions.
- Vehicle photo crop/framing tool with zoom, drag positioning, preview, saved crop settings, and reset.
- Version footer on every screen.
- CSV/XLSX import support with mapping, preview, validation, and duplicate detection.
- Record ID and Entry Sequence.
- Entry Type and Data Quality.
- Vehicle Acquisition Date and Starting Odometer.
- Optional Fuel Price Per Gallon, Total Fuel Cost, and Fuel Cost Source.
- Root-level icon files only.
- README.md plus versioned README with identical content.

## Changed

- User-facing app name is now RGB Mileage.
- Build/package shorthand is RGBM.
- Backups and exports include version number and date.

## Deferred

- Supabase database storage.
- AI receipt scanning and automated fuel-cost extraction.
