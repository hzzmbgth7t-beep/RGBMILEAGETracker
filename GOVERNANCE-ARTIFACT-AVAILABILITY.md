# Governance Artifact Availability Rule

**Governance version:** 1.1  
**Status:** APPROVED

A deliverable is complete only after:

1. the archive is created
2. the archive passes integrity verification
3. archive contents match the intended source
4. the recipient confirms it can be downloaded
5. any UI presentation difference is recorded without inventing a cause

A filename link and a `Download` control are both acceptable when the recipient confirms successful access.
