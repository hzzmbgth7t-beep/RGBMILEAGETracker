# RGB Mileage Tracker

Version: **v2.1.5b**  
Release type: **Maintenance Screen Merger Release**

## Purpose
This release applies the accepted Fuel merged-screen model to **Maintenance**. Maintenance now uses one screen with **Empty**, **View**, and **Edit** states. Fuel remains on the accepted merged model, and Insurance remains on the prior separate View/Edit model.

## What This Release Changes
- Maintenance uses one unified screen instead of separate Maintenance View/Edit flows
- Vehicle **Maintenance Entry** opens Maintenance in **Edit**
- Maintenance tap on Previous Records opens **View**
- Maintenance long press on Previous Records opens **Edit**
- Maintenance supports:
  - **Empty** state
  - **View** state
  - **Edit** state
- **Data Information** is available in both Maintenance View and Maintenance Edit
- Maintenance **Previous Records** remains expanded on the Maintenance screen
- Fuel remains on the accepted merged model
- Insurance is unchanged structurally in this release
