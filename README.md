# RGB Mileage Tracker

Version: **v2.1.4g**  
Release type: **Fuel Screen Merger Release**

## Purpose
This release starts the structural screen-merger phase by converting **Fuel** to a unified workflow. Fuel now uses one screen with **Empty**, **View**, and **Edit** states. Maintenance and Insurance remain on their current separate View/Edit model in this release.

## What This Release Changes
- Fuel uses one unified screen instead of separate Fuel View/Edit flows
- Home circle tap opens Fuel in **Edit**
- Vehicle **Quick Fuel Entry** opens Fuel in **Edit**
- Fuel supports:
  - **Empty** state
  - **View** state
  - **Edit** state
- Fuel tap on Previous Records opens **View**
- Fuel long press on Previous Records opens **Edit**
- **Data Information** is available in both Fuel View and Fuel Edit
- Fuel **Previous Records** remains expanded on the Fuel screen
- Maintenance and Insurance are unchanged structurally in this release

## What This Release Does Not Change
- no Maintenance merger
- no Insurance merger
- no Delete / Deleted Items workflow
- no broader responsive/orientation work
- no broader home-screen layout redesign

## Why This Release Exists
This release begins the new structural-improvement version line. It uses Fuel as the lowest-risk template before applying the same model later to Maintenance and Insurance.
