# RGB Mileage Changelog

Version: 2.0.11  
Release Date: 2026-06-04  
Build Type: Corrective / Stability Update  
Based On: v2.0.10

## Added

- Unified Quick Fuel Entry/Edit workflow.
- Edit mode for Quick Fuel Entry.
- Save Edit button state.
- Cancel Edit button.
- Edit save acknowledgment that keeps the user on the Quick Fuel Entry page.
- New entry save acknowledgment before returning to Home Screen.

## Changed

- Previous fuel entry Edit no longer uses prompt dialogs.
- Editing a fuel entry now uses the same fields and calculations as Quick Fuel Entry.
