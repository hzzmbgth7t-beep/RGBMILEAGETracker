# RGB Mileage Tracker

Version 1.0

RGB Mileage Tracker v1.0 is a browser-based Progressive Web App (PWA) for tracking fuel mileage, fuel type, fuel grade, station history, vehicle maintenance, ownership information, and insurance information for up to two vehicles.

## How to Use

Open `index.html` in Safari or host the folder using any static web server. Add it to the iPhone Home Screen for an app-like experience.

## Included Files

- `index.html` — full PWA application
- `manifest.webmanifest` — PWA manifest
- `service-worker.js` — offline cache support
- `assets/` — app icons
- `RGB_Mileage_Tracker_UserGuide_v1.0.pdf`
- `README_v1.0.md`
- `CHANGELOG_v1.0.md`
