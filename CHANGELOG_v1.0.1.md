# CHANGELOG v1.0.1

Release Date: 2026-06-01

## New Features

- Added manual current-location lookup to the fuel entry screen.
- Added Location field to fuel entries.
- Added Clear Location button.
- Added station detection workflow:
  - Use This Station?
  - Location Only
  - Cancel
  - Add To Station Drop Down List?
- Added hidden latitude and longitude storage.
- Added station/location report support.

## Changed

- Updated in-app version display to 1.0.1.
- Updated README and User Guide to v1.0.1.
- Preserved root-level icon paths and Apple touch icon support.

## Known Issues

- Reverse geocoding depends on internet access and third-party map data.
- iOS may cache Home Screen icons; delete the old icon before adding the updated app.
