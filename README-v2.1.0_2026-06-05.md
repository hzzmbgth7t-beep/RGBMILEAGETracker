# RGB Mileage

Version: 2.1.0
Release Date: 2026-06-05
Build Type: Architecture Stabilization Release
Schema: v2.1.0

RGB Mileage v2.1.0 is the first build aligned to the reconciled RGB Mileage Master Specification v1.0.

Included:
- Vehicle record-preservation architecture
- Vehicle Acquisition records
- Fuel, Maintenance, and Insurance record modules
- Previous Records sections
- Tap row to expand/collapse
- Long press row to View Record
- View/Edit safety workflow
- Archive instead of delete
- Classification tags: Imported, Historical, Archived
- Data Quality: Verified, Review, Estimated
- JSON backup/restore
- CSV import preview/save reviewed rows
- Root-level flat-file GitHub Pages structure

Deferred:
- XLSX import
- OCR receipt scanning
- Cloud sync
- Multi-user support
- Restore merge mode
