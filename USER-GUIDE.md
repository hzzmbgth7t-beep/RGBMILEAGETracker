## v2.1.6f Addendum - Fuel Edit Button Layout

This version changes the Fuel edit-screen button layout for existing records.

### Fuel Edit Screen Layout
- Row 1: **New** | **View**
- Row 2: **Delete** | **Save**
- Row 3: blank | **Cancel**

### Behavior
- Save behavior is unchanged
- Delete behavior is unchanged
