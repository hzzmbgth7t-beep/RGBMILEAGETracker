# User Guide

**Build:** `v2.1.6l-wc10-f15`  
**Build date:** `08/01/2026`  
**Governance:** `v1.7`

A green shield reading:

```text
Update
Offline
Service
Worker
```

means the visible app is running while a newer offline service worker is waiting for activation.

Open **Settings → Offline Mode → Apply Offline Update**. The app reloads after activation and the shield disappears.

The shield is informational. It does not indicate data loss or a failed GitHub deployment.
