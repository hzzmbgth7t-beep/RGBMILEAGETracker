## After deployment

1. Launch the existing Home Screen app.
2. Confirm `Download Recovery Snapshot` is visible near the top.
3. Tap the button.
4. Save the downloaded JSON file.
5. Confirm the file is present in Files or Downloads.
6. Send that snapshot for reconciliation.

## Do not proceed farther

The pending state contains only two configured vehicles.

The latest three-vehicle backup contains fewer fuel, maintenance, and insurance records than the standalone state.

Do not tap pending recovery and do not restore the backup until a non-reducing merged recovery candidate is prepared.
