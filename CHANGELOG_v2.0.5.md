# RGB Mileage Change Log v2.0.5

## New Features
- Clean build from scratch.
- Restored vehicle-circle Home Screen.
- Added official RGB Mileage naming.
- Added Quick Fuel Entry from vehicle circle tap.
- Added Vehicle Details via long press.
- Added tabbed Vehicle Details screen.
- Added Record ID, Entry Sequence, Entry Type, and Data Quality support.
- Added CSV/JSON import preview and validation.
- Added JSON backup/restore.
- Added fuel receipt attachment support.
- Added fuel price fields using two decimal places.

## Changes
- Dashboard removed from Home Screen and moved to Reports.
- Home Screen uses icon-only bottom navigation.
- Flat-file deployment enforced.

## Known Issues / Deferred Items
- XLSX import is specified but not fully parsed in this local-only build.
- Complete ZIP backup with embedded attachments is specified but data-only JSON is implemented first.
- Push notifications are specified but require deployment/browser support.
- Receipt OCR is deferred.
