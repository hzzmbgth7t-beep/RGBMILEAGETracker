# RGB Mileage v2.1.3e

RGB Mileage v2.1.3e is a stabilization patch based directly on v2.1.3d.

## Primary Fixes

- Corrected displayed version to v2.1.3e.
- Corrected displayed build date to 2026-06-08.
- Preserved existing local data key during the patch to reduce upgrade data-loss risk.
- Reduced Home screen movement and bounce while preserving content screen scrolling.
- Restored tap-to-view behavior for previous records.
- Changed previous-record long press to 750ms for Edit.
- Restored missing Cancel button beneath Save on Fuel, Maintenance, and Insurance Edit screens.
- Adjusted record navigation so Back returns to the prior app screen/menu instead of cycling through record history.
- Added runtime orientation-lock attempt in addition to manifest portrait setting.

## Deferred

- Previous Record button.
- Session record-history navigation.
- Side-by-side Save/Cancel layout.
