# CLEAN-INSTALL-NOTE

This package is the pruned clean-install release for RGBMileage v2.2.0.

Purpose:
- Include only release-authority deployment files
- Exclude legacy PMR/EMR/history/control clutter from the install package

Included classes:
- Runtime web/PWA files
- Current release-facing documentation
- Current config-patch verification note
- Current icons/assets required by the app

Excluded classes:
- Historical PMR/EMR/control records
- Prior-version review documents
- Legacy planning packages
- Archived notes not required for deployment

Control note:
- Historical records should be maintained in separate records/archive packages, not in the clean install zip.
